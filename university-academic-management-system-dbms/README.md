# University Academic Management System - DBMS

## Project Description
The University Academic Management System is a DBMS project designed to manage students,
faculty, departments, courses, enrollments, and results efficiently. It stores academic
data in related tables and uses primary keys, foreign keys, UNIQUE, NOT NULL and CHECK
constraints to maintain data integrity.
